# almost-ship-it

Everything ship-it does, except the merge.

**Say:** "almost ship it", "ship it but don't merge", "get it ready to merge"

It proves the change, has review-loop check it, opens the PR and babysits it until it's ready to merge. Then it stops and leaves the merge to you. Say "ship it" when you're happy.
